# Mushroom Atlas — Lab Assignment 2

[Русский](README.ru.md) | **English**

A dependency-free JavaScript field guide to mushrooms of central Russia, designed as a vintage botanical atlas.

## Included in this repository

- Search, category filters, sort order, add/delete form, and browser storage are implemented in `js/app.js`.
- CSS-only light and dark themes use responsive card layouts.
- The original assignment screenshots and a browser-check script are included.

## Getting started

Open `index.html`, or serve the repository with `python -m http.server 8000` and visit `http://localhost:8000`. No install or build step is required.

## Notes

User-added text is rendered as text and entries are stored in browser `localStorage`. See `tests/browser-check.js` for the documented checks.
